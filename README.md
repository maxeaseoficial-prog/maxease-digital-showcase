# MAXEASE Digital Vision

Vamos desenvolver um novo site institucional para a MAXEASE Digital.

O objetivo é criar um site extremamente moderno, tecnológico e premium, que transmita inovação, criatividade e profissionalismo.

Este site será o principal canal comercial da empresa.

A referência de qualidade deve ser semelhante a grandes agências digitais internacionais.

Não quero um layout genérico.

Quero um design exclusivo.

Objetivo

O resultado final deve transmitir que a MAXEASE Digital é uma empresa moderna, inovadora e de alto padrão, capaz de desenvolver sites, sistemas e produções audiovisuais para empresas que buscam crescer. O site deve causar impacto logo nos primeiros segundos e servir como vitrine da qualidade técnica da empresa, fazendo com que potenciais clientes pensem: "Se o site deles é assim, quero ver o que podem fazer pelo meu negócio."
